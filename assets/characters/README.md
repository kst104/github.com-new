# 잘.의.정.바 고정 캐릭터 7종 (종이인형 마스터)

2026-11-24 승태 님이 확정한 **3D 병원 조감도 배경 + 검은 테두리 2D 종이인형** 컨셉의 마스터 에셋.
기준 샘플: `downloads/sample_day18_3d_paperdoll_black.png`

## 파일

| 이름 | 파일 | 역할 | 추천 캐릭터명 |
| :--- | :--- | :--- | :--- |
| 의사 | `doctor.png` | 흰 가운·청진기·검지로 설명하는 포즈 | 닥터 온 |
| 남자 어린이 | `boy.png` | 6~8세, 초록 스웨터·청바지·빨간 운동화 | 몽이 |
| 여자 어린이 | `girl.png` | 6~8세, 분홍 가디건·데님 스커트 | 콩이 |
| 성인 남성 | `adult_man.png` | 30~40대, 하늘색 셔츠·네이비 슬랙스 | 보람 |
| 성인 여성 | `adult_woman.png` | 30~40대, 민트 블라우스·베이지 슬랙스 | 가온 |
| 할아버지 | `grandpa.png` | 60~70대, 둥근 안경·베이지 니트 조끼 | 느티 |
| 할머니 | `grandma.png` | 60~70대, 회색 파마·로즈 가디건 | 포근 |

- 원본(흰 배경): `assets/characters/<이름>.png`
- 투명(RGBA): `assets/characters/<이름>_transparent.png` — 테두리 바깥 흰 배경만 제거, 종이 여백·검은 테두리는 유지
- 배경: `assets/backgrounds/clinic_bg_4x3.png`(블로그 1200x900) · `clinic_bg_9x16.png`(쇼츠 1080x1920) — 위에서 내려다본 대형병원 3D 조감도를 은은하게 블러. 선명 원본은 `*_선명원본.png`
- 라인업: `downloads/잘의정바_7캐릭터_라인업.png`(2400x1200) · `downloads/잘의정바_7캐릭터_시트.png`(1600x800)
- 배포용 묶음: `downloads/캐릭터_7종/`(개별 PNG + `투명배경/`), `downloads/잘의정바_7캐릭터_종이인형.zip`

## 제작 스크립트

- `scripts/paperdoll_cutout.py` — 흰 배경 → RGBA 컷아웃(테두리에서 연결된 흰색만 투명 처리)
- `scripts/make_hospital_bg.py` — 조감도 원본을 규격·블러 처리
- `scripts/make_paperdoll_illustration.py` — 배경 + 캐릭터 + 노란 메모지(PIL 한글) 합성, 라인업 시트 생성

## 화풍 규격 (재생성 시 프롬프트 고정값)

- 2D 플랫 카툰, 셀 셰이딩, 큰 머리(chibi, 3등신 안팎)
- 캐릭터를 감싸는 **두꺼운 흰 종이 여백 + 바깥을 잡아 주는 균일한 검은 테두리**(가위로 오린 종이인형)
- 순수 흰 배경, 그림자 없음, 글자 없음
- 따뜻한 크림·세이지 팔레트, 큰 갈색 눈, 볼터치

## 사용 규칙

- 블로그 삽화: 배경 위에 캐릭터를 세우고 오른쪽 위 **노란 메모지**에 핵심 요약 3~4줄(PIL 렌더링, 폰트 `NotoSansCJKkr-Regular`)
- 주제에 맞는 캐릭터만 쓴다(예: 밤 가려움 → 의사+할머니+엄마·여자아이+성인 남성)
- 쇼츠는 투명 PNG 파츠를 배경 위에 얹어 까딱까딱 움직이는 연출에 쓴다.
