# 잘.의.정.바 3단 레이아웃 규격 (의학 쇼츠 기본값)

2026-11-20 승태 님 확정. 유튜브 쇼츠·인스타 릴스 공통 **1080×1920 세로**, 앞으로 만드는 의학 쇼츠의 기본 레이아웃이다.
확정 시안: `downloads/Day13_잘의정바_1장시안_v2.png` (승태 님이 "네 그렇게 해줘요"로 확정).

## 1. 3단 구조

| 단 | y 범위 | 내용 |
| :--- | :--- | :--- |
| 상단 1/3 | `0 ~ 540` | 흰색 배경 `#FFFFFF`. 1줄 굵은 검정 훅 + 2줄 주황 박스(`#EE6C1E`) + 흰 굵은 글씨 |
| 중단 영역 | `540 ~ 1400` | 칠판 일러스트/영상 본문 1080×860, 좌우 꽉 차게. 하단 중앙에 한 줄 자막 |
| 하단 여백 | `1400 ~ 1920` | 흰색 배경. `y ≈ 1422`에 작은 회색 안내문, 그 아래는 쇼츠 UI 여백으로 비움 |

### 상단 1/3
- 1줄: `잘못된 의료 정보 바로잡기` (고정 기본값). 주제에 맞는 후킹 소제목으로 바꿀 수 있다(`top_line`).
- 2줄: `잘.의.정.바 · <핵심 주제 키워드>` — 주황 박스 안 흰 굵은 글씨. 키워드는 씬별로 바뀐다.
- 글자가 넓으면 폰트가 자동으로 줄어 1080 폭을 넘지 않는다.
- **실명(`김승태`, `닥터 김승태`)은 넣지 않는다.** 채널 브랜드(`잘.의.정.바`)만 노출.

### 중단 영역
- 칠판 아트는 1080×860을 **비율 유지 크롭(cover)** 으로 채운다. 원본이 정사각(1254×1254)이면 상하 약 110px씩 잘린다(`crop_bias`로 위/아래 치우침 조정 가능).
- **초기 2초 배지**: 영상 시작 `0.0s <= t < 2.0s` 동안만 중단 영상 상단 중앙(`y = 565`, 높이 66px 박스)에 반투명 주황(`#EE6C1E`, alpha 235) 알약 + 흰 굵은 글씨 `구독·알림·좋아요는 힘이 됩니다`(36px)를 얹고, 2.0s 직전 0.45초 페이드 아웃으로 자연스럽게 사라진다(첫 프레임은 선명하게 시작 · 자막과 겹치지 않음 · `subscribe_badge=False`로 끌 수 있음).
- 자막: 영상 하단 중앙(`y = 1400 - 96`), **검정 외곽선 + 굵은 흰색 한 줄**. 폰트는 폭에 맞춰 자동 축소(52 → 34px).
- 자막 문구는 씬의 `caption`을 쓴다. 없으면 `main_text`의 줄들을 ` · `로 이어 만든다(두 줄 이상이면 자동 2단 분할).

### 하단 여백
- 안내문: `잘.의.정.바 · 자세한 칼럼은 프로필 링크` (회색 `#696969`, 28px).
- 그 아래는 유튜브 쇼츠 UI(좋아요·댓글·채널명·설명)가 덮는 자리이므로 **아무것도 그리지 않는다**.

## 2. 엔진 사용법

`engine/chalkboard_video_engine.py`

```python
from engine.chalkboard_video_engine import render_chalkboard_shorts

render_chalkboard_shorts(scenes, "out.mp4")                 # 기본값 = 잘.의.정.바 3단 (layout="jaljab")
render_chalkboard_shorts(scenes, "out.mp4", layout="chalkboard")  # 기존 전면 칠판 프레임 재현
```

씬 dict에서 3단 레이아웃이 쓰는 키:

| 키 | 쓰임 | 비고 |
| :--- | :--- | :--- |
| `chalk_img` | 중단 아트 | 필수 |
| `keyword` (또는 `brand_keyword`) | 상단 주황 박스 키워드 | 짧게(8~12자) |
| `caption` | 중단 한 줄 자막 | **한 줄로 읽히는 문장** 권장. 없으면 `main_text`로 대체 |
| `top_line` | 상단 1줄 | 생략 시 `잘못된 의료 정보 바로잡기` |
| `voice` | 내레이션 | Edge-TTS `ko-KR-InJoonNeural`, 숫자는 한글 발음으로 |
| `badge` / `sub_text` | (3단 모드에서는 미사용) | 과거 회차 대본 호환용으로 남겨 둠 |

음성 없이 컷 이미지만 뽑을 때(승태 님이 "1장 스크린샷"을 요청할 때):

```python
from engine.chalkboard_video_engine import render_jaljab_previews
render_jaljab_previews(scenes, "content/<회차>/chalkboard/jaljab_preview")
```

## 3. 검증 결과 (2026-11-20)

- 1080×1920, 상단 `y≤520` 흰색 / 중단 `540~1399` 아트 / 하단 `1410~1900` 흰색 확인.
- 주황 박스가 상단 밴드 안(y 366~470)에 위치, 자막 흰색 픽셀·안내문 회색 픽셀 확인.
- 2씬 테스트 MP4 실제 렌더 완료: 1080×1920 · 25fps · 12.19초 · AAC 오디오 (TTS 포함 전 구간 정상).
- 기존 `layout="chalkboard"` 프레임도 그대로 렌더되어 과거 회차 재현이 깨지지 않음을 확인.
- 초기 2초 배지: 정지 프레임 검증(배지 y 565~631, 주황 21,403px·배지 없음 0px) + 실제 2씬 MP4 8.39초 렌더로 `t=1.0s` 배지 있음(20,384px) / `t=2.6s` 배지 없음(0px) 확인 후 테스트 MP4 삭제.
